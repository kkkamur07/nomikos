Features

AI drafts. You review.

  • AI-assisted transcription

    Run segmentation and line HTR so the page arrives with proposed regions and readings. Review the AI work. Correct what needs a human eye. That is how you get more pages done.

  • Page editor

    Compare model output with ground truth on the same canvas. Edit segments or text in place. Keep layers separate per model or pass.

  • Local or cloud inference

    Install the nomikos-inference agent, pair it with your account, and run OCR and segmentation on your own CPU with weights cached on disk. It opens no port. It takes pages from the queue and reports back. Hosted inference runs the same program.

  • Projects and export

    Organize manuscripts into projects. Publish live pages. Export line crops and transcriptions for training pipelines.

About

Open research tooling

Nomikos is the annotation platform behind the NOMOS project: a hosted editor, open HTR models on Hugging Face, and an optional command-line inference agent you install with uv tool install nomikos-inference. Pair it once with nomikos pair, then leave nomikos run working through the queue. New models arrive as a new release of the package.
